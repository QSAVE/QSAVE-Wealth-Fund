# QSAVE brand assets

Logo files for the QSAVE token, published so listing surfaces
(Etherscan, CoinMarketCap, CoinGecko, aggregators) can fetch them
directly over HTTPS.

| File | Use |
|---|---|
| `QSAVE32-32tokenimage.svg` | Etherscan token logo (32×32) |
| `QSAVE-logo-200x200.png` | CoinMarketCap listing logo (200×200) |
| `QSAVE-logo-512-512.png` | General / high-resolution use (512×512) |
| `QSAVE-logo.svg` | Full vector mark |

Assets only. No source code, no documentation, no protocol material.
